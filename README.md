# ג'פטו אומנות בעץ — אתר עסק

אתר שיווקי לעסק של אמנות עץ ומזוזות בעבודת יד, עם לוח ניהול מובנה שמאפשר לבעל/ת העסק לערוך
בעצמם תמונות, מחירים, לוגו ותוכן — בלי לגעת בקוד.

## מה יש באתר

- **עמוד בית** עם לוגו, שם העסק, סיפור, גלריית עבודות ומחירון.
- **כפתור "הזמינו עכשיו"** (בכותרת, בעמוד הבית, ביצירת קשר, וכפתור צף) שפותח שיחת וואטסאפ מוכנה מראש.
- **מוכן לגוגל** — תגיות מטא, Open Graph ו-JSON-LD של עסק מקומי (Schema.org).
- **לוח ניהול** — נפתח ב-5 לחיצות רצופות על הלוגו, מוגן בקוד בן 4 ספרות. מאפשר לערוך את הכל: לוגו,
  תמונות גלריה (כולל מיקום וזום לכל תמונה), מחירים, טקסטים, טלפון, כתובת, שעות פעילות ואינסטגרם.
  כולל מסך "כמה פניות התקבלו" עם רשימת הפניות האחרונות.
- **מצב כהה** אוטומטי (לפי הגדרת המכשיר של המבקר).
- **רספונסיבי** לנייד, טאבלט ומחשב.

## איך להריץ מקומית

זהו אתר סטטי (HTML/CSS/JS) ללא תלות בשרת. מריצים שרת מקומי:

```bash
python3 -m http.server 8000
```

ואז פותחים: http://localhost:8000

## כניסה ללוח הניהול

לוחצים **5 פעמים ברצף** על הלוגו בכותרת האתר (תוך כדי כ-1.5 שניות) — נפתחת תיבת קוד בת 4 ספרות.
אפשר גם להיכנס ישירות דרך הכתובת עם `#admin` בסוף (למשל `https://your-site/#admin`).
בכוונה **אין קישור גלוי** לניהול באתר עצמו, כדי שמבקרים רגילים לא יראו או ילחצו עליו בטעות.

**קוד ברירת מחדל:** `6767`
חשוב להחליף אותו מיד בלוח הניהול → "סנכרון וסיסמה" → "שינוי קוד ניהול". אם מחוברים לסנכרון בענן
(ראו למטה), הקוד מתעדכן אוטומטית לכל המכשירים — לא צריך להגדיר אותו בנפרד בכל מקום.

⚠️ ההגנה בקוד מתאימה לעסק קטן ומיועדת למנוע גישה מקרית — היא **לא** ברמת אבטחה בנקאית
(הנתונים באתר עצמם אינם רגישים: תמונות, מחירים וטקסט).

## פריסה ל-GitHub Pages (כדי לקבל קישור לשליחה ללקוחות)

1. **Settings → Pages** במאגר הזה.
2. **Source**: Deploy from a branch.
3. **Branch**: בוחרים את הענף שבו עובדים (או ממזגים ל-`main` קודם) ו-`/ (root)`.
4. שומרים. תוך דקה-שתיים הקישור יהיה זמין, בפורמט:
   `https://<שם-המשתמש>.github.io/<שם-המאגר>/`

### קישור מקצועי יותר

- אפשר לשנות את **שם המאגר** (Settings → General → Repository name) לשם שמתאים לעסק
  (למשל `gepetto-woodcraft`) — זה משפר את הקישור.
- לקישור הכי מקצועי — דומיין אישי (למשל `www.gepetto-wood.co.il`) שמפנים אליו: קונים דומיין
  (כ-50-70 ש"ח לשנה), ומגדירים ב-Settings → Pages → Custom domain. יש להוסיף גם רשומת CNAME/A
  אצל ספק הדומיין לפי ההוראות שמופיעות שם.

## סנכרון בענן (חשוב להבנה!)

**המאגר הזה (`gepetto-woodcraft`) כבר מחובר** — פרטי הפרויקט מוגדרים ישירות בקוד
(`BUILTIN_FIREBASE_CONFIG` ב-`app.js`), כך שכל מבקר באתר מתחבר אוטומטית לאותו מסד נתונים
משותף, בלי צורך בהגדרה נפרדת בכל מכשיר. גם לוח הניהול וגם עדכוני התוכן והפניות עובדים מכל
מכשיר מהרגע הראשון.

הסעיף הבא רלוונטי רק אם משתמשים בקוד הזה כתבנית לאתר **חדש**, של עסק אחר, שעדיין לא חובר
לשום פרויקט Firebase — במקרה כזה `BUILTIN_FIREBASE_CONFIG.apiKey` יהיה ריק, והאתר יחזור
למצב "כל מכשיר שומר מקומית" עד שיחברו פרויקט (דרך התיבה בלוח הניהול, או ישירות בקוד).

### הגדרת סנכרון Firebase (לתבנית חדשה שעדיין לא חוברה)

1. נכנסים ל-[console.firebase.google.com](https://console.firebase.google.com/) עם חשבון Google.
2. **Add project** → בוחרים שם (למשל `gepetto-woodcraft`) → ממשיכים (אפשר לדלג על Analytics).
3. בתפריט הצד: **Build → Firestore Database → Create database** → **Start in test mode** →
   בוחרים אזור (מומלץ `europe-west`) → Enable.
4. **Project settings** (גלגל השיניים למעלה) → **General** → גוללים ל-**Your apps** →
   אייקון **Web (`</>`)** → רושמים אפליקציה (לא צריך Firebase Hosting).
5. מעתיקים את אובייקט ה-`firebaseConfig` שמוצג.
6. באתר: לוח ניהול → "סנכרון וסיסמה" → מדביקים את ה-config בתיבה → "התחברות וסנכרון".
7. זהו — מעכשיו כל שינוי בלוח הניהול (מכל מכשיר שמחובר לאותו Firebase) מסתנכרן לכל מבקרי האתר
   בזמן אמת, וכל הפניות דרך "הזמינו עכשיו" נרשמות ונספרות בלוח הניהול.

**הערה:** Firestore במצב Test mode פתוח לכל מי שיש לו את קובץ ה-config למשך 30 יום. זה מספיק
לשימוש רגיל (העסק הוא היחיד שמחזיק את ה-config), אך לאחר מכן Firebase יבקש לעדכן את כללי
האבטחה — אפשר להמשיך במצב פתוח (Firestore אינו מאחסן מידע רגיש כאן) או להגביל כתיבה לפי הצורך.

## מה עוד כדאי לעשות כדי "לעלות לגוגל" בפועל

1. להגדיר **Google Business Profile** (business.google.com) עם שם העסק, כתובת/אזור שירות,
   טלפון וקישור לאתר — זה מה שגורם לעסק להופיע במפות ובחיפוש המקומי.
2. לרשום את הכתובת ב-**Google Search Console** (search.google.com/search-console) ולשלוח
   בקשת אינדוקס לדף הבית — כך גוגל "רואה" את האתר מהר יותר.

## מה עדיין צריך למלא באתר (רשימה לבעל/ת העסק)

שם העסק, הלוגו, טקסט "על העסק", מספר הוואטסאפ ושלוש תמונות עבודה אמיתיות כבר בפנים. נשאר:

- [ ] **בדיקת המחירון** — המחירים כרגע הערכה ראשונית, בעל העסק יעדכן בעצמו (לוח ניהול → מחירון)
- [ ] תמונות עבודה נוספות לגלריה, אם יש (לוח ניהול → גלריית עבודות)
- [ ] כתובת, שעות פעילות וקישור לאינסטגרם — אופציונלי (לוח ניהול → סנכרון וסיסמה)
- [ ] קוד ניהול חדש, במקום ברירת המחדל `6767`
