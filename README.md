# מתכנן חופש גדול 🌞

אפליקציית web פשוטה לתכנון פעילויות החופש הגדול לחניכים — מתחשבת בתאריכי החופשה של 4 המדריכים ובסוגי הפעילויות.

## תכונות

- **4 מדריכים** (2 מדריכים, 2 מדריכות) — כל אחד מסמן את הימים שבהם הוא לא יכול להגיע.
- **פעילויות לפי סוג:**
  - 🟣 כל המחנה — דורש את כל 4 המדריכים פנויים.
  - 🟦 מפוצל לפי מגדר — בנים עם המדריכים, בנות עם המדריכות (כל ה-4 צריכים להיות פנויים).
  - 👦 בנים בלבד — דורש את 2 המדריכים פנויים.
  - 👧 בנות בלבד — דורש את 2 המדריכות פנויות.
- **זיהוי קונפליקטים אוטומטי** — האפליקציה מזהירה אם יש מדריך/ה בחופש בימי פעילות.
- **הצעת תאריכים פנויים** — לוחצים על "הצע תאריך פנוי" וההצעה הראשונה שמתאימה תופיע.
- **לוח קיץ מסכם** — תצוגת חודש-אחר-חודש עם צבעים שמראים מה קורה בכל יום.
- **ייצוא/ייבוא נתונים** — כדי לשתף את התכנון בין המדריכים.

## תאריכים

החופש הגדול: **18.6.2026 — 26.8.2026** (70 ימים).

## איך מריצים

זו אפליקציית HTML/CSS/JS סטטית. צריך פשוט לפתוח את `index.html` בדפדפן, או להריץ שרת מקומי:

```bash
python -m http.server 8000
```

ואז לפתוח: http://localhost:8000

## אחסון נתונים

**ברירת מחדל:** הנתונים נשמרים ב-LocalStorage של הדפדפן. שורד סגירת דפדפן והפעלה מחדש, אבל לא משותף בין מכשירים.

**אופציה: סנכרון בענן (Firebase)** — חינמי, ב-5 דקות הגדרה חד-פעמית, ואז כל ה-4 מדריכים רואים את אותם נתונים בזמן אמת מכל מכשיר.

### הגדרת סנכרון Firebase

1. נכנסים ל-[console.firebase.google.com](https://console.firebase.google.com/) עם חשבון Google.
2. **Add project** → שם: `summer-camp-planner` → ממשיכים (אפשר לדלג על Analytics).
3. בתפריט הצד: **Build → Firestore Database → Create database** → **Start in test mode** → אזור `europe-west` → Enable.
4. **Project settings** (גלגל שיניים למעלה) → **General** → גוללים למטה ל-**Your apps** → אייקון **Web (`</>`)** → רושמים אפליקציה.
5. מעתיקים את `firebaseConfig` שמופיע.
6. באפליקציה: לוחצים על "☁️ סנכרון" בכותרת → מדביקים את ה-config → בוחרים קוד קבוצה (למשל `kayitz-2026`) → "התחבר וסנכרן".
7. שולחים את קוד הקבוצה ל-3 המדריכים האחרים — הם מזינים את ה-config ואת הקוד במכשיר שלהם וכל השינויים מסתנכרנים אוטומטית.

**הערה:** Firestore במצב test mode פתוח לכל מי שיש לו את ה-config למשך 30 יום. אחרי זה, ניתן להוסיף כלל בטיחות פשוט שמאפשר רק את הגישה למסמכי המחנה שלכם.
