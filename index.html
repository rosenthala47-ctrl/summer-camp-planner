🟢 מחובר

כל שינוי מסתנכרן אוטומטית עם 4 המדריכים.

שלח את קוד הקבוצה ל-3 המדריכים האחרים. הם יזינו אותו בטלפון שלהם וכל השינויים יסתנכרנו בזמן אמת.

📖 איך מקימים פרויקט Firebase (פעם אחת, חינם, 5 דקות)
  1. נכנסים ל-console.firebase.google.com (עם חשבון Google).
  2. לוחצים Add project → שם: summer-camp-planner → ממשיכים (אפשר לדלג על Google Analytics).
  3. אחרי שהפרויקט נוצר, בתפריט הצד: Build → Firestore Database → Create database.
  4. בוחרים Start in test mode → אזור europe-west → Enable.
  5. חוזרים ל-Project settings (גלגל שיניים למעלה) → General → גוללים למטה ל-Your apps → לוחצים על אייקון ה-Web (</>).
  6. נותנים כינוי לאפליקציה → Register app.
  7. מעתיקים את אובייקט firebaseConfig שמופיע (החלק שמתחיל ב-{ apiKey: "...", ... }) ומדביקים פה למטה.

⚠️ קונפליקט עם פעילות מתוכננת

הנתונים נשמרים בדפדפן שלך. השתמש ב"ייצוא נתונים" כדי לשתף עם מדריכים אחרים.
